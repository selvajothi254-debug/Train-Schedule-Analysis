# Train Schedule Analysis

## Project Overview
This project focuses on analyzing train schedule data to understand train timings, routes, station frequency, and journey durations. It also includes an interactive train enquiry system to find available trains between selected stations.

## Project Files
- Train_Schedule_Analysis.ipynb – Complete Python analysis and train enquiry system.
- Dataset1.csv – Original train schedule dataset.
- Level3_Verified_Dataset.csv – Verified and processed dataset.
- Project_Report.pdf – Project report.
- Outputs – Analysis screenshots.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Key Features
- Data loading and exploration
- Data cleaning and preprocessing
- Missing value and duplicate checking
- Train route and station analysis
- Journey duration calculation
- Short, Medium, and Long route classification
- Station-wise train frequency analysis
- Data visualization using charts
- Pivot tables and cross-tabulation
- Interactive train enquiry system

## Objective
To analyze train schedule data, identify useful patterns, visualize insights, and provide an interactive way to check available trains between selected stations.

## Conclusion
This project demonstrates practical skills in Python programming, data cleaning, data analysis, data visualization, and working with real-world datasets.
